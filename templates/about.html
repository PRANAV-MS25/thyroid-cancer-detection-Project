About ThyroidDetect

ThyroidDetect is an advanced, AI-powered diagnostic web platform designed for the rapid automated screening and classification of thyroid nodules from ultrasound scans. Built to assist medical workflows, it integrates deep learning models with secure session handling and automated HTML medical report generation via SMTP.
